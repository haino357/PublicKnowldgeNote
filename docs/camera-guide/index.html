Starter kit

最初に買うものは、少なくていい

使い始めて不足が分かるまでは、望遠レンズや三脚を先回りして買う必要はありません。

  1. カメラ＋標準ズームまずはキットレンズで焦点距離の好みを発見。
  2. 128GB SDカード写真中心はUHS-I。高ビットレート動画は指定速度を確認。
  3. ブロアー＋クロスレンズ表面のほこりを安全に手入れ。
  4. 持ち歩ける小型バッグ入る大きさより、実際に持ち出せる軽さを優先。
