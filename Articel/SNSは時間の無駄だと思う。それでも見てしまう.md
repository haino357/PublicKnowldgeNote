# SNSは時間の無駄だと思う。それでも見てしまう

![[SNSは時間の無駄だと思う。それでも見てしまう_noteサムネイル.png]]

SNSは、負の感情を燃料にして、さらに負の感情を増幅させる装置なのではないか。

タイムラインを眺めていると、そんなことを考える。怒り、不満、嘲笑。それらに触れているうちに、こちらまで気分が悪くなる。「もう法で規制した方がいいのでは」と、気の迷いまで生じるほどには、自分も毒されているらしい。

普段は、表現の自由との兼ね合いもあり、法規制は難しいと思っている。それでも、そんな考えが頭をよぎるくらいには、うんざりすることがある。

それほど嫌なら、見なければいい。

理屈ではそう思う。実際、見終わったあとには「この時間は何だったのだろう」と感じることも多い。それでも、また開いてしまう。たまに「面白い」が「時間の無駄」を上回る瞬間があるからだ。

ずっと退屈なら、きっとやめやすい。けれど、時折どうしようもなく面白い投稿や、妙に興味を引かれる投稿に出会う。その一瞬があるせいで、次も何かあるのではと指を動かしてしまう。自分にとってのSNSは、そんな蟻地獄に近い。

興味を引かれるものの中には、笑って済ませにくいものもある。

たとえば、高い学歴や専門知識を持っているように見える人が、次第に陰謀論めいた言説に傾いていく。その過程が、投稿の履歴として残っていることだ。

かつては根拠を確かめ、慎重に語っていたように見えた人が、いつの間にか、信じたい話ばかりを集めるようになる。自分に都合のいい情報を積み重ね、確信を深めていく。

ここで念頭に置いているのは、自然科学や形式科学に関わる人だけではない。人文科学や社会科学に関わる人も含め、根拠を吟味し、反論を検討することに慣れているはずの人たちのことだ。

もちろん、投稿だけでその人の思考のすべてが分かるわけではない。それでも、普段なら疑うはずの話を、信じたいという理由で受け入れているように見える場面がある。知識や学歴だけでは防げないものがあるのだろうと感じる。反面教師として、これほど生々しい記録もないと思う。

ただ、そうやって他人を眺めている自分にも、少し嫌なものを感じる。

「この人は信じたい情報だけを集めている」と見抜いたつもりになりながら、自分もまた、他人の矛盾や失敗を面白がって見続けている。しかも、その観察を「勉強になる」と言い換えれば、見続ける口実までできてしまう。

冷静に観察しているつもりでも、その面白さに引き留められている。

結局、SNSは時間の無駄だと思う。それでも、見てしまう。

この矛盾を解決する答えは、今のところ持っていない。ただ、他人が何かに飲み込まれていく様子を眺めている間に、自分の時間も静かに吸い込まれている。

そこまで分かっていて、またタイムラインを開こうとする。反面教師には、自分も含まれている。
